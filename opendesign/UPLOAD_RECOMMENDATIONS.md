# OpenDesign upload recommendations

Upload the most useful visual materials first. Each asset teaches OpenDesign something different.

1. Logo / wordmark
- Teaches brand name, typography, and how formal the identity should feel.

2. Landing page screenshot
- Teaches first-impression tone, sport segmentation, and hero hierarchy.

3. Dashboard screenshot
- Teaches KPI density, chart styling, metric emphasis, and overall coach-grade posture.

4. Submissions page screenshot
- Teaches list/card density, processing status patterns, retry actions, and report affordances.

5. Drill upload screen screenshot
- Teaches form layout, calibration controls, helper-copy style, and file-upload emphasis.

6. Drill library screenshot
- Teaches how drill guidance, sport grouping, and reference links should be presented.

7. Admin screen screenshot
- Teaches the densest information hierarchy in the product and how logs, overrides, and model tools should look.

8. Privacy page screenshot
- Teaches the tone for export/delete flows and consent-aware system messaging.

9. Consent screen screenshot
- Teaches how parental approval should be framed: clear, careful, and not overly harsh.

10. Mobile screenshot
- Teaches whether cards, navigation, and form controls still work on smaller screens.

11. Empty state screenshot
- Teaches what the product should do when there is no data yet.

12. Loading / in-progress state screenshot
- Teaches how the app should show queueing, upload progress, and processing activity.

13. Any approved sports imagery or brand photography
- Teaches whether imagery should feel real, premium, and performance-oriented rather than decorative.
